# 数据与隐私

## 本机存储

macOS 用户数据默认在：

`~/Library/Application Support/DeskChatGPT/state/`

主要包括：

- `state.db`：目录和连接授权、操作记录、截图、变更计划和适用的恢复数据。
- 记住的运行密钥：仅在选择保存时加密写入本机，由 macOS Keychain 保护。
- 私有配置和连接信息：不得复制到公开 Git 仓库，也不应放进问题反馈。
- 迁移数据库备份和 `state.desktop/`：可能随历史升级和 Electron 桌面状态留存。

## 保留范围

- 最近最多约 **10,000 条**操作记录，截图最多约 **100 张**，还会受到记录轮换影响。
- 终端和 Git 保留有界的已结束任务元数据；单项任务输出最多约 **64 KiB**，运行时内存输出可能在服务重启后消失。
- 变更计划和可恢复数据与普通操作记录的清理范围不同；清理历史不应当作撤销文件改动。

## 如何清理

在「操作记录 → 管理本机记录」可以分别清理操作记录和截图；在「工作台 → 整理旧数据」可以对过期任务记录执行范围核对。清理前检查保留范围，相关操作可能无法撤销。

如需撤销本机存储的运行密钥，可在「连接设置」忘记已保存的密钥，并在 OpenAI Platform 使原密钥失效。已经返回 ChatGPT 的内容需要在 ChatGPT 中另行管理，本机清理不能删除云端对话。
