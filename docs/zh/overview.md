# 产品介绍

**DeskChatGPT 让 ChatGPT 使用你明确授权的 Mac 本机能力。** 它是一款独立开发的桌面工具，而不是聊天客户端或 AI 模型。你仍在 ChatGPT 中发起任务；DeskChatGPT 负责接收本机 MCP 工具调用、检查权限、执行操作并返回结果。

它不提供 ChatGPT 账号、模型或订阅，也不是 OpenAI 官方产品。**是否能从 ChatGPT、Dot 或 Codex 的某个入口调用，取决于该入口对已连接工具的支持与实际授权，不能仅凭本机显示已连接就认定所有模式可用。**

## 五类核心能力

| 能力           | 你能做什么                                                                                   | 需要什么授权                                             |
| -------------- | -------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 本机文件与项目 | 列出目录、全文和文件名检索、读取文件、创建、修改、精确补丁、移动、删除、批量处理与支持的恢复 | 事先选择的目录；写入按只读、逐项确认或直接读写策略执行   |
| 终端与 Git     | 运行开发命令、构建和测试、查看输出、跟踪/停止任务、执行 Git 操作                             | 独立开启；命令以当前系统用户运行，**不受文件夹授权隔离** |
| 独立浏览器     | 打开和阅读网页、点击、填写表单、截图                                                         | 单独开启；与日常浏览器资料分离                           |
| macOS 桌面控制 | 查看应用、打开应用、读取屏幕及获准的窗口键鼠操作                                             | 单独开启；还需要 macOS 辅助功能与屏幕录制系统权限        |
| 操作记录与恢复 | 核对任务状态、授权变化、文件改动、执行回执和支持的恢复                                       | 属于本机记录；不能替代云端聊天记录                       |

## 典型使用场景

- **了解一个已有项目：** 先只读授权项目目录，再让 ChatGPT 搜索源码、分析结构和解释功能。
- **修改并验证代码：** 对测试工程开启逐项确认写入，审核差异后执行修改；如需跑构建或测试，再独立开启终端与 Git。
- **跨文件批量任务：** 在明确授权的目录中执行批量改动。每项都有实际操作结果；部分成功时不假装整个批次已经回滚。
- **网页操作或桌面辅助：** 分别启用浏览器或桌面能力；网页、屏幕内容可能返回 ChatGPT，应避开敏感资料。
- **在多台电脑之间选择目标：** 给每台 Mac 分配独立 Tunnel 与自定义 MCP 工具，在 ChatGPT 中选择需要操作的电脑。

## 一次任务如何完成

```text
ChatGPT 对话 → 自定义 MCP 工具 → 当前 Mac 专属 Tunnel
             → DeskChatGPT 本机服务 → 权限检查与本机审批
             → 文件 / 终端 / 浏览器 / 桌面操作
             → 结果与回执返回 ChatGPT
```

1. 你在 OpenAI Platform 准备私有 Tunnel，并在支持的 ChatGPT 工作区配置对应的自定义 MCP 工具。
2. 在 DeskChatGPT 的「连接设置」连接这台电脑；在「工作台」授权所需目录。
3. 如需终端、浏览器或桌面能力，分别开启；需要本机批准的操作由本人确认。
4. 使用原 ChatGPT 对话发起任务。执行结果、文件变更和适用的恢复操作可以在「操作记录」核对。
5. 遇到超时或连接中断，先查询任务、变更计划和实际回执。**结果未知不等于没有执行，不能直接重复写入。**

## 在多台 Mac 之间选择

家里和公司可以各安装一份 DeskChatGPT，**每台 Mac 拥有自己的私有 Tunnel、密钥和目录授权**。例如配置 `@DeskChatGPT-家里` 与 `@DeskChatGPT-公司`，在同一个支持相应工具的 ChatGPT 工作区选择目标。

不同电脑不会自动同步文件或权限；这里的“切换”是**选择要调用的 MCP 工具**，不是共享目录或远程桌面。

## App 中的四个页面

- **工作台：** 管理已授权目录、读写策略和相关变更。
- **连接设置：** 连接当前 Mac、查看 Tunnel 状态、独立开启终端、浏览器和桌面能力。
- **操作记录：** 查看任务和文件改动回执，处理可核对的未知结果与本机记录。
- **使用文档：** 产品介绍、快速上手、授权与安全、数据与隐私、常见问题。

## 权限、安全与限制

目录有**只读、读写逐项确认、直接读写**三种策略。模型不能自行批准本机授权；删除文件不进入废纸篓。终端在你的系统账户下运行，不受目录授权限制，浏览器和桌面操作也需独立授权。
