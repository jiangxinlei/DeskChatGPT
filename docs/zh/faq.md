# 常见问题

## 电脑显示已连接，但 ChatGPT 调用不到

检查 ChatGPT 的工作区、DeskChatGPT 自定义 MCP 工具和 Tunnel ID 是否一致。在插件设置刷新工具，并新建 Chat 对话重新选择。连接中断时，在本机「连接设置」复制诊断摘要；不要提交运行密钥。

## 读取不到文件或无法写入

确认目录已授权给当前连接。只读模式不能写入；逐项确认模式需要在 Mac 上批准变更计划。如果原计划已失效，请先重新读取文件再生成新计划。

## 文件变更的撤销为什么提示冲突？

可能是文件后来被编辑、移动，或者原路径已被其他内容占用。先备份现状，再核对差异；不要盲目覆盖。

## 旧截图没有缩略图

保存截图功能启用前的记录可能只有操作摘要。新截图也可能因数量上限或日志轮换被清理。可回到原 ChatGPT 对话查看当次工具结果。

## 可以在家里和公司的两台 Mac 之间切换吗？

可以。每台 Mac 独立安装 DeskChatGPT，各自创建 **不同 Tunnel**，并在**同一个 ChatGPT 工作区**分别添加一个自定义 MCP 工具。可将名称设置为 `DeskChatGPT-家里`、`DeskChatGPT-公司`（或你习惯的 `LocalGPT-家里`、`LocalGPT-公司`）。

在 ChatGPT 中使用 `@` 选择 `@DeskChatGPT-家里` 或 `@DeskChatGPT-公司`，该任务就会交给对应在线的 Mac；每台 Mac 分别管理目录权限和本机审批，密钥、文件和权限不自动共享。使用前确认选择的确实是目标电脑。
