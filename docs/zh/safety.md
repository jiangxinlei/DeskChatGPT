# 授权与安全

## 选择目录权限

| 模式            | 含义                                                       |
| --------------- | ---------------------------------------------------------- |
| 只读            | 查看、查找、读取所授权目录及其子目录，不允许写入           |
| 读写 · 逐项确认 | 创建改动计划，在 Mac 本机检查并批准每项写入                |
| 直接读写        | 允许在已授权目录内直接创建、修改、移动、删除，不再逐项弹窗 |

**只授权任务确实需要的目录。** 切换权限或撤销目录会使相关未执行计划失效。模型不能自行扩大授权范围。

## 文件变更与恢复

- 批准前核对目录、文件名、原内容、修改内容及完整哈希。删除文件不会进入废纸篓。
- 普通文件创建和全文替换的内容上限为 **64 KiB**；经授权的普通 UTF-8 文件读取、精确补丁和删除支持最多 **8 MiB**。
- 批量改动一次最多 20 项，按顺序执行；中途失败不会自动撤销已经完成的项目。
- 文件若在改动后再次变化，或路径被占用，恢复可能发生冲突。不要在没有检查磁盘状态的情况下重复执行未知写入。
- 当结果未知时，在本机检查可用证据并结束或确认计划；**核对不会重新执行写入**。

## 独立能力权限

**终端与 Git** 以当前系统用户身份执行命令，并不受已授权文件夹范围限制，可能访问其他文件或网络。请独立批准，必要时停止任务。

**独立浏览器** 可以读取、点击和填表；敏感登录、付款和提交应由本人在窗口里核对。

**桌面控制** 使用 macOS「录屏与系统录音」及「辅助功能」系统权限，截图之前应关闭敏感窗口。

## 终端执行模式

在 Mac 上打开「连接设置 → 终端与 Git → 执行模式」。设置仅作用于当前连接，ChatGPT 无法切换。

- **受保护执行（默认）**使用 DeskChatGPT 的外层沙箱保护本机授权状态和 App。SwiftPM、Xcode、Firefox 等尝试自行启用沙箱的工具可能受限。
- **原生执行**需要在 Mac 上确认身份。命令使用当前账户的权限，保留工具自身的沙箱。命令可以访问或修改该账户有权访问的文件，包括 DeskChatGPT 本机状态，也可以访问网络。仅对信任的连接和命令启用。

切换模式时，DeskChatGPT 会先停止当前连接的终端任务。关闭终端权限或重启本机服务后，恢复受保护执行。

## 已知安全边界

本机文件守卫拒绝多种不可信链接与路径逃逸，但同目录中的**非协作外部写入进程**仍可能在最终基线核对与操作之间产生竞态。不得把共享的不可信目录宣称为安全隔离区。请对重要资料备份，并阅读仓库的 [安全说明](https://github.com/jiangxinlei/DeskChatGPT/blob/main/SECURITY.md)。
